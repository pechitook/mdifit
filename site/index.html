How it works

Read, comment, copy. That’s the loop.

01

Open a folder

Point it at your plans, specs or docs. Folders open with their README or AGENTS.md.

npx mdifit docs/

02

Comment while you read

Select a phrase and press C to comment or S to suggest a rewrite. It stays a quiet mark in the margin.

…workers consume them with at-least-once delivery.

03

Copy one prompt

Press P. Every note becomes file:line plus your feedback, ready to paste into your agent.

The prompt

Every note, one paste.

Locations are relative to where you ran mdifit, quotes travel with each note so they survive edits, and suggested edits come as before / after. The same format as difit, so your agent already knows it.

Works with Claude Code, Codex, opencode, or any chat.

Features

A reader first. A review tool when you need it.

Comments in the margin

A soft underline and a bubble. Nothing pushes the text around while you read.

Suggested edits

Propose the exact rewrite and preview it inline before you save it.

Folders that make sense

A breadcrumb, a file tree, and folders that open with their README or AGENTS.md.

Search everything

⌘K finds files, headings and text across the folder, accents ignored.

Mermaid diagrams

Rendered like GitHub, light or dark, loaded only when a file has one.

Live while agents write

The page updates as files change, and a file edited after you read it says so.

Reading progress

Mark files read and pick up where you left off: next unread is one key away.

Local and private

Runs on localhost, reads only your folder, writes nothing. Comments stay in your browser.
